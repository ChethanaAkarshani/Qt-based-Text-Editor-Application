# Qt Text Editor Application

A feature-rich desktop text editor developed using **C++** and the **Qt Framework**. The application provides a clean and intuitive user interface for creating, editing, and managing text documents while offering productivity-enhancing features such as automatic capitalization and text correction.

## Features

### File Management
- Create new documents
- Open existing text files
- Save documents
- Save As functionality

### Text Editing
- Cut, Copy, and Paste operations
- Undo and Redo support
- Easy document editing through a user-friendly interface

### Smart Writing Assistance
- Automatic capitalization at the beginning of sentences
- Basic auto-correction functionality
- Detection of punctuation-related writing issues
- Real-time text monitoring and correction

### User Interface
- Built using Qt Widgets
- Clean and responsive desktop application design
- Easy-to-use menu-driven interface

## Technologies Used

- C++
- Qt Framework
- Qt Widgets
- Qt Creator
